# Changelog

## v2.0.0 — The Clean Slate Update (April 2026)

### What's New
- **Photo Filters Fixed:** Orientation, Size, and Color filters now work reliably when searching for wallpapers.
- **Privacy Policy:** Added an in-app Privacy Policy accessible from Settings.

### Improvements
- **Onboarding Screen:** Fixed system navigation bar overlap at the bottom of the onboarding flow.
- **Codebase Overhaul:** Removed all legacy dead code from the previous architecture, resulting in a leaner and faster app.
- **Play Store Compliance:** Removed unnecessary location permissions and dependencies.
- **Unused Resources Cleaned:** Removed orphaned drawable assets and default color resources.

### Removed
- "Support the Developer" section from Settings (will return in a future update with a better implementation).
